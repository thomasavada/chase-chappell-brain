# 33% rule

Watch: [Facebook ad creatives in 2027](https://youtu.be/jDt1eCJpfO0) — **t=9:06** awareness table

In **one ad set**:

- Source: in-house / UGC army / AI (about a third each)
- Funnel: TOF / MOF / BOF — **5+5+5** unique formats

Andromeda sequences who sees which stage. Do **not** split TOF/MOF/BOF into separate campaigns.

**2026 anti-pattern:** find a winner, clone variants of the same format → fatigue → account dies.

**Sign you did it:** spend is **leveled** across ads, not stuck on 1–2 winners.

Keep the “ugly” 2x unaware ad. It is doing a funnel job. [[Awareness ladder]]

Unique = 100% different format (review vs features vs founder vs problem/solution), same brand colors/fonts.

## Static library before launch (claimed, [13h](https://youtu.be/8AAIf5PWJik))

Stock 5–10 formats, each unique: features & benefits · notes-based · product ~80% of frame · scarcity/drop · VIP list · review/PR · welcome kit (front-end 0–2x, LTV 3–7x claimed). The 33% rule is what you *do with* that library after Andromeda — not a reason to clone the winner.

## Volume vs spend (claimed, 13h)

| Spend / mo | Unique ads in flight (claimed) |
|---|---|
| $0–10K | 5–30 |
| $10–50K | 30–100 |
| $300K+ | ~250 via Flexible Formats, broad-only |

3x spend still needs ~3x **unique formats**. [[Metric diagnosis tree]]
