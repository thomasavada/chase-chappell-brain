# Hims diagnostic layer

Watch: [How Hims and Hers built an $8B brand](https://youtu.be/FVDTvDZ-0TQ)

Claimed: 710 Hims ads / 600+ Hers. They did not win by selling pills.

- Do not say "you have hair loss." Sell timeline, self-esteem, dating.
- Quiz: **goal first**, email after sunk cost. Segment receding vs crown.
- Delivery mechanism (powder / gummy / gel).
- Site answers: is this normal / does it work / is it safe / is it for me.
- Pull toward a solution. Most brands push a product.
