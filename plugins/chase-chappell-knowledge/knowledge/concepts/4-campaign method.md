# 4-campaign method

Watch: [Andromeda](https://youtu.be/ZLFWruC2iEw) · [Scale Facebook ads 2026](https://youtu.be/s_g4JYSRRow)

Few campaigns. Many unique creatives.

1. **Creative testing** — 10–20 variations, own budget. Winners migrate out.
2. **Interest testing** — only if you still need it; Andromeda prefers Advantage+ broad.
3. **Advantage+** — winners only, broad. Audience segments: engaged-never-buy vs customers 180 days. Scale the **new-customer** ad set.
4. **Retargeting** — cap. If you skip it, Meta self-retargets and frequency explodes.

Scale: **+20% every 3–4 days** at ad-set (don’t reset learning). Past ~$200/day → CBO. Past $500/day → +$100 / $250 / $500 every 3 days.

Vertical scale breaks ROAS → creative problem → go horizontal (new unique formats).
