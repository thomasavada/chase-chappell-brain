# Resolver — which kind of task reads what first

There is **one skill:** `teach-chase`. It reads a knowledge file, then teaches one scenario.

| When the user wants | Read first |
|---|---|
| To be taught / any Chase topic | skill `teach-chase` (classroom: one combo → guess → one job) |
| Facebook ads / stuck account | `concepts/Chase classroom.md` + `concepts/Metric diagnosis tree.md` — [t=9:36](https://youtu.be/42uhZYnyEXU?t=936) |
| Campaign structure / scale | `concepts/4-campaign method.md` |
| Andromeda / matchback / Hub / Euka | `concepts/Andromeda stack.md` |
| What ads to make | `concepts/33 percent rule.md` |
| TikTok Shop / affiliates | `concepts/TikTok Shop army.md` |
| Why subscriptions | `concepts/Three levels of purchase.md` |
| Brands Chase mentioned | `brands/Brand atlas.md` |
| Hims / diagnostic quiz | `concepts/Hims diagnostic layer.md` |
| Positioning / villain | `concepts/Five levels of brands.md` |
| AI ads / MCP | `concepts/AI creative stack.md` |
| A specific video | `knowledge/sources/` + Watch column |
| Graph / "how does X connect to Y" | `graphify query` on repo `graphify-out/` then the cited note |

**General rule:** consult the brain before speculating. If the file is missing, **say so**. Do not fill from generic ads advice.

**Freshness:** knowledge files carry `verified:`. Quote it when older than 30 days.

**Not this brain:** Avada/Joy product, WeTracked/CAPI clones, private ad accounts.
